💧 Water Watch: Local Water Supply and Complaint Analysis 1. Project Description Water Watch is a web-based application designed to improve local water supply monitoring and complaint management. It allows users to view water supply status information for different areas, register complaints about water-related problems, and analyze complaints through a dashboard. The system focuses on common water problems such as water leakage, irregular water supply, low water pressure, dirty water, and water shortages. Its main objective is to simplify complaint reporting, improve public awareness, and support better local water management. Note: This is a prototype. Water supply information is not connected to live government data. 2. Technologies Used - HTML5: Structures the website content. - CSS3: Provides styling and a mobile-friendly design. - JavaScript: Implements interactive features, complaint registration, and dashboard calculations. - Browser Local Storage: Stores complaint data locally in the user's browser. - GitHub: Hosts and manages the source code. - GitHub Pages: Publishes the website online. 3. Features 1. Area-wise Water Supply Status: Select an area to view demonstration status information. 2. Complaint Registration: Submit water-related complaints using a form. 3. Complaint Reference ID: Generate a reference number for each submitted complaint. 4. Complaint Analysis Dashboard: Display total, pending, and resolved complaints. 5. Complaint Categorization: Organize complaints by type to identify common water problems. 6. Complaint Status Management: Mark complaints as resolved or reopen them. 7. CSV Report Download: Download complaint records for further analysis. 8. Responsive Design: Access the website using mobile phones, tablets, and computers. 4. Installation Instructions Option 1: Access the Live Website 1. Open a web browser. 2. Visit: https://saimeghana-art.github.io/Water-watch/ 3. Select an area to view the demonstration water supply status. 4. Enter the required information to register a complaint. 5. View the complaint dashboard and reports. Option 2: Run the Project Locally 1. Open the GitHub repository: https://github.com/saimeghana-art/Water-watch 2. Click the Code button. 3. Select Download ZIP. 4. Extract the downloaded ZIP file. 5. Open the extracted project folder. 6. Open "index.html" in a web browser. 7. Test the available website features. No additional software installation is required to run the basic HTML, CSS, and JavaScript prototype. 5. Future Enhancements - Integration with verified, real-time water supply information. - Backend and database for permanent complaint storage. - Shared complaint tracking across multiple users and devices. - Notifications about water supply interruptions and complaint updates. - Interactive maps showing reported water problems. 6. Limitations - Water supply status is not currently connected to live government data. - Complaints are stored in browser local storage and are not automatically shared with other users or the water department. - Clearing browser data may remove locally stored complaints. - A backend and shared database are required for permanent, multi-user complaint management. 7. Project Objective To develop a simple and accessible digital platform that helps communities report local water supply problems and analyze complaint patterns to support better water management. 8.
